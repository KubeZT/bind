KubeZT®

Get bound to a KubeZT® cluster.

Bind turns your developer workstation into a cluster-ready developer environment: identity-based network access, approved artifacts, kubeconfig, kubectl, and the KubeZT command line in one guided flow.

Before You Bind
Cluster Identity Get the zero trust identity for the cluster with the admin role assigned.
Artifact Keys Have the AWS access key ID and secret provided by your administrator.
Cluster Name Use the exact cluster name provided by your administrator.
Workstation Use Bash or Zsh on macOS or Linux, or PowerShell on Windows.
Verified Access Scoped keys retrieve only the approved cluster artifacts.
Active Cluster Kubeconfig, kubectl, and kubezt are ready in the shell.
01

Install Client

Install the zero trust client for your platform so private KubeZT endpoints are reachable from your workstation.

02

Enroll Identity

Load the identity provided by your administrator and confirm the client is connected.

03

Run Bind

Run the command, enter the provided artifact access keys, and activate the cluster in your shell.
